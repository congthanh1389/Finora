FINORA OPTIMIZED SVG ICON SYSTEM
=================================

Icons: 29
Canvas: 24x24
Vector: path/circle/rect only; no embedded PNG/JPEG.
Stroke: 1.8, round caps/joins.
Color: currentColor, so the same SVG can follow the app theme.
Background: transparent.

Recommended React Native usage:
- Use react-native-svg for direct SVG rendering.
- Keep these source files as the canonical icon assets.
- For navigation tabs, use 24px; for larger cards, render at 28-32px.
- Avoid recoloring individual files; control color from the component/theme.

This set is a clean vector redraw inspired by the Finora design language, not a raster image wrapped in SVG.
